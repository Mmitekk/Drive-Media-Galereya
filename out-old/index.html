Медиа Галерея — Настройка
Для работы приложения нужен Cloudflare Worker — серверный прокси, который скрывает API-ключ Google Drive и управляет доступом.

Шаг 1: Задайте NEXT_PUBLIC_WORKER_URL

Добавьте в файл .env.local:

NEXT_PUBLIC_WORKER_URL=https://your-worker-name.workers.dev

Это URL вашего Cloudflare Worker (создаётся на следующем шаге).

Шаг 2: Создайте Cloudflare Worker

  1. Зарегистрируйтесь на dash.cloudflare.com (бесплатно, без кредитной карты)
  2. Перейдите в Workers & Pages
  3. Нажмите Create application → Create Worker
  4. Дайте имя, например dmga-api
  5. Скопируйте код из файла worker/index.ts проекта
  6. Вставьте в редактор кода Worker и нажмите Deploy

Шаг 3: Настройте секреты Worker

В настройках Worker (Settings → Variables) добавьте секреты:

DRIVE_API_KEY          = Ваш Google Drive API ключ
DRIVE_ROOT_FOLDER_ID   = ID корневой папки Google Drive
ADMIN_PASSWORD         = Пароль для входа как администратор
JWT_SECRET             = Случайная длинная строка (минимум 32 символа)
TOKEN_SALT             = Случайная длинная строка (минимум 32 символа)

Готово!

После настройки откройте сайт, введите пароль администратора и создайте гостевые ключ-файлы для других пользователей.
